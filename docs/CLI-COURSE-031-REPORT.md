# CLI-COURSE-031: отчёт

Пример демонстрирует интеграционное тестирование CLI как отдельного процесса. Решение содержит приложение и xUnit-тесты; тестовый проект ссылается на приложение и запускает собранную DLL через dotnet.

## Проверки

- Windows, .NET SDK 10.0.404, System.CommandLine 3.0.0.
- `dotnet build CLIAppsCourse.slnx`: успешно, 0 предупреждений, 0 ошибок.
- `dotnet test CLIAppsCourse.slnx --no-build`: четыре последовательных запуска в целевом репозитории, каждый: 12 пройдено, 0 ошибок, 0 пропусков.
- `dotnet publish examples/31-process-testing/MyCli/MyCli.csproj -c Release -r win-x64 --self-contained false`: успешно; опубликованный mycli.exe с `echo --text "hello world"` вывел `hello world` и завершился с кодом 0.
- Покрыты help, ошибки разбора, неизвестная команда, потоки и коды, пути с пробелами, рабочий каталог, временные файлы, stdin, тайм-аут и большие выводы одновременно в оба потока. Содержимое входных файлов после сканирования проверяется.

## Ограничения

- Ссылка на статью ожидает публикации.
- Native AOT и другие ОС не проверялись. Проверка опубликованного приложения выполнена на Windows x64 с установленным runtime.
- Тайм-аут проверяет завершение процесса sleep; создание дочерних процессов в тестовом CLI не демонстрируется, хотя runner вызывает Kill с entireProcessTree.
- Локальные ссылки Git могут устареть: сетевые Git-операции не выполнялись.
