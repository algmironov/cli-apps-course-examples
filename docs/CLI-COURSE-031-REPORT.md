# CLI-COURSE-031: отчёт

Пример демонстрирует интеграционное тестирование CLI как отдельного процесса. Решение содержит приложение и xUnit-тесты; тестовый проект ссылается на приложение и запускает собранную DLL через dotnet.

## Проверки

- Windows, .NET SDK 10.0.404, System.CommandLine 3.0.0.
- `dotnet build CLIAppsCourse.slnx`: успешно, 0 предупреждений, 0 ошибок.
- `dotnet test CLIAppsCourse.slnx --no-build`: четыре последовательных запуска в целевом репозитории, каждый: 12 пройдено, 0 ошибок, 0 пропусков.
- `dotnet publish examples/31-process-testing/MyCli/MyCli.csproj -c Release -r win-x64 --self-contained false`: успешно; опубликованный mycli.exe с `echo --text "hello world"` вывел `hello world` и завершился с кодом 0.
- Покрыты help, ошибки разбора, неизвестная команда, потоки и коды, пути с пробелами, рабочий каталог, временные файлы, stdin, тайм-аут и большие выводы одновременно в оба потока. Содержимое входных файлов после сканирования проверяется.

## Ограничения

- Ссылка на статью ожидает публикации.
- Native AOT и другие ОС не проверялись. Проверка опубликованного приложения выполнена на Windows x64 с установленным runtime.
- Тайм-аут проверяет завершение процесса sleep; создание дочерних процессов в тестовом CLI не демонстрируется, хотя runner вызывает Kill с entireProcessTree.
- Локальные ссылки Git могут устареть: сетевые Git-операции не выполнялись.

## Исправления после code review

Исходный runner ограничивал только запись stdin и ожидание процесса; чтение потоков и очистка не имели ограничения времени, прочие исключения не инициировали очистку, а потомок мог удерживать открытые дескрипторы. Теперь общий тайм-аут включает ожидание обоих потоков, при любой ошибке выполняется попытка завершения дерева и очистка ограничена пятью секундами. Гонка между проверкой выхода и Kill учитывается. Ошибка очистки передаётся вместе с исходной ошибкой, а внешняя отмена отличается от тайм-аута. Сам Process.Start является синхронным вызовом и таймером не ограничен.

Добавлены тест внешней отмены и ограничение времени теста тайм-аута, подготовка файлов перенесена внутрь try/finally, имя теста потоков исправлено. После исправлений на Windows выполнены `dotnet build CLIAppsCourse.slnx` (успешно, 0 предупреждений и ошибок) и четыре прогона `dotnet test CLIAppsCourse.slnx --no-build` (каждый: 13 пройдено, 0 ошибок и пропусков). Проверка Windows CIM до и после трёх повторных прогонов не нашла процессов dotnet/mycli с mycli.dll или mycli.exe в командной строке.

Сценарий потомка, унаследовавшего дескрипторы, отдельным тестом не воспроизводился: для него потребовался бы вспомогательный исполняемый процесс. Если исходный процесс уже завершился, runner не гарантирует обнаружение и завершение потомков; незакрытые потоки приводят к ошибке очистки после ограниченного ожидания. Проверка Ctrl+C не выполнялась. Проверка Native AOT и других ОС не выполнялась.
